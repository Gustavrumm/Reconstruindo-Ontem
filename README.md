# Reconstruindo-Ontem
O objetivo geral deste estudo é desenvolver a estrutura lógica de um banco de dados relacional voltado a geração de resumos matinais, funcionando como tecnologia assistiva para pessoas com amnésia anterógrada. Como objetivos específicos, pretende-se, adaptar os princípios do método do "Segundo Cérebro", identificar as entidades essenciais empregando lógica SQL e estabelecer o embasamento teórico da ferramenta quanto à capacidade de diminuir a dependência da memória biológica.
